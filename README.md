## AIM

To create a personal Portfolio using HTML only.

## ALGORITHM

### STEP 1

Create an HTML file named `index.html`.

### STEP 2

Define the basic HTML document structure using `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>` tags.

### STEP 3

Add a title and metadata using appropriate HTML tags.

### STEP 4

Create a header section with your name and professional title.

### STEP 5

Include a navigation menu using the `<nav>` tag with links to different sections.

### STEP 6

Create structured sections for Home, About Me, Education, Technical Skills, Projects, Certifications, and Contact Details.

### STEP 7

Add your professional photograph using the `<img>` tag with appropriate width, height, and alt attributes.

### STEP 8

Use HTML headings, paragraphs, ordered lists, and unordered lists to organize the content.

### STEP 9

Add hyperlinks using the `<a>` tag to connect different sections and external profiles.

### STEP 10

Use tables and HTML alignment attributes to organize and align the portfolio content.

### STEP 11

Separate different sections using the `<hr>` tag for better readability.

### STEP 12

Add a footer section using the `<footer>` tag with copyright information.

### STEP 13

Open the HTML file in a web browser to check the layout and functionality.

### STEP 14

Correct any errors and verify that all navigation links and images work properly.

### STEP 15

Upload the HTML file and required images to a GitHub repository.

### STEP 16

Deploy the portfolio using GitHub Pages and verify the published website.

## PROGRAM

The HTML program is available in `index.html`.
